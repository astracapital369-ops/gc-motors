# GC Motors

Application d'achat-revente de voitures (garage, marges, ventes, garanties), installable sur téléphone et PC.

- `index.html` : l'application
- `firebase-config.js` : configuration Firebase (synchronisation entre appareils)
- `firestore.rules` : règles de sécurité à coller dans Firebase > Firestore > Règles
- `manifest.webmanifest`, `sw.js`, `icons/` : installation sur l'écran d'accueil
